# Getting Started

Ten minutes from `git clone` to a running TrainingBench with the
shipped math-example agent ready to query.

For the full install reference (operator-level detail, troubleshooting,
systemd setup, verification steps), see [Install]({{ '/install.html' | relative_url }}).

## Prerequisites

- **Linux** host (Debian/Ubuntu is the documented example)
- **Python 3.11+**
- **NVIDIA GPU** with ≥16 GB VRAM (RTX 3090 verified) — for adapter
  training (Track A). **Or CPU-only** for Track B (RAG + inference
  only, no fine-tuning).
- **~30 GB disk space** for the install + base model download
- An email you want admin notifications to come to

## Step 1 — Clone and set up Python

```bash
git clone https://github.com/eversole-learning/trainingbench
cd trainingbench
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Step 2 — Configure environment

```bash
cp .env.example .env
```

Open `.env` and set at minimum:

```
DEFAULT_ADMIN_EMAIL=you@your-address.com
```

That's it for a basic install. Everything else is auto-generated on
first boot:
- **Admin password** — random 24-char password printed to stdout +
  written to `logs/first-run-admin.txt`
- **SECRET_KEY + PASSWORD_SALT** — auto-generated to `backend/db/.secrets`

## Step 3 — Start the backend

```bash
python -m uvicorn backend.api.main:app --host 0.0.0.0 --port 8000
```

Watch the startup log. You should see:

```
[secrets] generated and wrote .../backend/db/.secrets (salt=generated-fresh)
[schema] {'migration_id': 'tb-us-051', 'seeded_default_agent': True}
[seeder] {'seeded': True, 'agent_id': 2, 'training_set_samples': 500, ...}
======================================
TB-US-049 FIRST-RUN ADMIN CREDENTIALS
  username: admin
  password: <auto-generated-password>
======================================
INFO:     Application startup complete.
```

## Step 4 — First login

Open **http://localhost:8000** in a browser. The gate page may ask
for a site passphrase if `SITE_PASSPHRASE` was set; by default no
gate.

Log in with `admin` + the auto-generated password from the stdout
banner. You'll be forced to the **password-change page** immediately —
set a new password (minimum 10 chars). The `logs/first-run-admin.txt`
file is deleted automatically on success.

## Step 5 — See what you have

Once logged in, the Chat tab shows the welcome banner. Click the
hamburger (top-left) to open the drawer. You should see:

- **Top of drawer:** 🤖 Current agent selector — `default` and
  `math-example` present
- **Nav items:** Chat / Upload / Scrape / PowerSearch / Documents /
  Databases / Training Sets / Training Runs / etc.
- **Bottom:** ⚙️ Admin dropdown (super-only) — Users + API Keys inside
- **Logout** below Admin

Switch to the **math-example** agent via the drawer dropdown. The
welcome banner updates to the 3-card variant.

## Step 6 — Try the shipped example

The math-example agent has three draft experiments pre-created, each
pinning a specific `(prompt, RAG, LLM, adapter)` combination for
measurement. Navigate to **Training Runs** and launch an adapter
training to produce a real adapter:

1. `+ Create Training Run`
2. Agent: `math-example`
3. Training set version: `v3 (500 samples)`
4. Base model: `meta-llama/Meta-Llama-3.1-8B-Instruct`
5. Hyperparameters: *leave defaults, or set `max_train_samples: 20`
   for a 5-minute smoke test*
6. 🚀 Launch Training Run

Watch the amber-pulsing active-run strip at the top of the page as it
reports step / epoch / loss / elapsed. You can close the browser; the
training keeps going. Log back in later; the strip is there with
status.

On completion, the trained adapter auto-registers as `v1` for the
math-example agent. Promote it to make it live. Re-run the experiments
to see measured accuracy with and without the adapter.

See [Staged Progression]({{ '/staged-progression.html' | relative_url }}) for the full
three-stage narrative.
