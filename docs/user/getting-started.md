# Getting started

This page walks you through logging in for the first time and
learning where things are.

## Logging in

TrainingBench instances typically have two authentication steps:

1. **Site passphrase gate** — a shared phrase your administrator
   gives out. This unlocks the login page for anyone with the
   phrase. You only enter it once per browser session.
2. **Personal login** — your own username and password. This is
   the account that tracks your queries and, for admin users,
   controls what you can do.

If your instance is configured without the passphrase gate, you
go straight to the personal login step.

Your administrator will provide the site passphrase, your
username, and an initial password. Change the password from your
profile once you are logged in.

## The dashboard

Once you are logged in, you see the main dashboard. What you
see depends on your **role**:

- **Chat role** — you see the Ask Questions (Chat) tab. Ask
  questions of the active database and read the answers. This
  is the most common role.
- **Training role** — you see the Ask Questions tab plus tools
  for rating answers. Your feedback helps improve the model.
- **Super role** — you see everything, including database
  management, document upload, and administrative controls.

The tabs across the top of the page let you switch between
capabilities. Only the tabs your role permits will be visible.

## The active database

Near the top of the page (or in a header control, depending on
your instance) you will see the **active database** name. This
is the database your questions will run against. If you have
multiple databases available and permission to switch, use the
selector to pick a different one. When you switch, the active
database updates immediately for you — other users on the same
instance are unaffected.

## Getting to help

The in-app documentation (this page and its siblings) is
reached from the **📖 Docs** button in the header of the main
dashboard. You can filter the list with the search box on the
left side of the docs viewer. Return to the app with the
**Back to App** button in the docs viewer's header.

For issues the docs do not cover, contact the person who
administers your TrainingBench instance.
