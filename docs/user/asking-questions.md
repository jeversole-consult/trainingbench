# Asking questions

The **Ask Questions** tab (also called the Chat tab) is the
primary way to get answers out of TrainingBench.

## The basic flow

1. Confirm the **active database** shown at the top of the page
   is the one you want to query. If it isn't, switch it using
   the database selector.
2. Type your question into the chat input at the bottom of the
   tab. Full sentences work well; keywords also work.
3. Press Send (or Enter). The system searches the active
   database for the most relevant material, then generates an
   answer that draws on what it finds.
4. Read the answer. If sources are shown, they point back to
   the specific documents the answer was drawn from.

## What makes a good question

- **Be specific.** "What are the deadlines for the Q3 report?"
  works better than "Tell me about reports."
- **Match your database.** If a topic is not in the loaded
  documents, TrainingBench will do its best but may return a
  weak answer or say it cannot find relevant material.
- **Ask follow-ups.** You can build on the previous answer with
  a follow-up question in the same conversation.

## Reading the answer

The answer typically shows:

- The generated response text.
- One or more **source citations** — filenames or excerpts the
  answer was based on. If a citation looks off, you can click
  through to inspect the source document.

## Clearing the screen

The Clear Screen button removes the messages from your display
so you can start a fresh conversation. It does **not** delete
any saved feedback data or the questions from the query log —
it's a display-only reset.

## For Training-role users

If you have the Training role, you will see rating controls next
to each answer:

- **✓ Acceptable** — the answer was correct, complete, and
  helpful.
- **✗ Needs Improvement** — the answer was wrong, incomplete,
  or unclear. You will be prompted to describe what was wrong,
  which helps improve the model.

Your ratings are collected and used to improve the AI over
time. The more high-quality feedback the system receives, the
better its answers become.
