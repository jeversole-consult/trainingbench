# Searching documents

The **Search Documents** tab performs a **semantic search**
across the active database. Use this when you want to find
specific content in your documents rather than ask a question
and get a generated answer.

## Search vs. Ask Questions

These two tabs solve related but different problems:

| You want to… | Use this tab | You get back… |
|---|---|---|
| Ask a question in plain language and get an answer | Ask Questions | A generated answer, plus source citations |
| Find passages in your documents that match a topic or query | Search Documents | A list of matching chunks with the document they came from |

If you know your documents contain the answer and you want to
see the *original text*, Search Documents gets you there
faster. If you want the platform to *synthesise* an answer,
use Ask Questions.

## How to search

1. Confirm the **active database** is the one you want to
   search.
2. Type your query into the search box. Full sentences work
   (semantic search understands meaning, not just keywords) but
   keyword queries also work.
3. Click **Search**.
4. Results appear as a ranked list of document chunks. Each
   result shows a snippet of text and identifies the source
   document.

## Tips

- **Use the query that matches your intent.** "Reasons for
  the delay" will find passages about causes and delays; the
  exact word "delay" doesn't have to appear.
- **Search returns chunks, not whole documents.** If you want
  the full document, note the source name and open it from
  the Manage Documents tab.
- **Very short queries can be noisy.** One or two words often
  return too many marginally relevant results. Adding context
  helps.
