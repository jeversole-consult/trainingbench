# TrainingBench — User Guide

Welcome. This guide covers how to use TrainingBench day-to-day.
It is written for people who will be **using** the platform to
work with a knowledge base and ask questions — not for people
who install or administer it.

## Where to start

- **[Getting started](getting-started.md)** — Logging in, finding
  your way around the dashboard, understanding what you're
  looking at.
- **[Asking questions](asking-questions.md)** — The Chat tab.
  The primary way to get answers from your knowledge base.
- **[Uploading documents](uploading-documents.md)** — Adding
  PDFs, Word docs, spreadsheets, and other files to a database.
- **[Managing documents](managing-documents.md)** — Organising,
  filtering, and removing documents you have already uploaded.
- **[Searching documents](searching-documents.md)** — Semantic
  search across your document collection when you want to find
  specific content, not ask a question.
- **[Power Search and Compare](power-search-and-compare.md)** —
  Advanced features that consult multiple AI services or two
  different database configurations side by side.

## The mental model

TrainingBench is a research assistant that answers questions
using **your own documents** as its source of truth. You upload
documents (or scrape webpages) into a **database**; the platform
converts them into a searchable form; then you ask questions in
plain language and get answers drawn from what you uploaded.

You can have **multiple databases** for different topics or
projects. At any time, one database is the **active** database —
that's the one your questions run against.

## When something goes wrong

If a page acts confused, refreshing the browser resolves most
transient issues. If a question comes back with an error or an
unexpectedly poor answer, check that the correct database is
active and that the topic you're asking about is actually
covered by the documents in that database.

For persistent issues, contact your system administrator.
